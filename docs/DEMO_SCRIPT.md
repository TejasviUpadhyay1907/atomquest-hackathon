## 🎬 Recording Tips

### Before Recording:
1. ✅ Clear browser cache
2. ✅ Close unnecessary tabs
3. ✅ Set browser zoom to 100%
4. ✅ Hide bookmarks bar
5. ✅ Use incognito mode (clean UI)
6. ✅ Prepare demo data (run seed_data.py)
7. ✅ Test all flows once
8. ✅ Have script open on second monitor

### During Recording:
1. ✅ Speak clearly and confidently
2. ✅ Move mouse slowly and deliberately
3. ✅ Pause briefly after each action
4. ✅ Highlight AI feature prominently
